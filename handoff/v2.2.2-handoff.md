# 交接单 · v2.2.2（桌面主页向日葵式改版）

- **分支**：`zc-v2.1.0`；**tag / Release**：`v2.2.2`；接续 v2.2.1（采集自愈）
- **交付物**：`zcdesk-2.2.2-x86_64.msi` / `.exe` / `rustdesk.sbom.json`
- **作者**：张翀 · 智策AI研发团队

## 1. 改了什么

- 主页信息架构对齐向日葵（用户给定参考图）：白色左导航 rail（品牌 logo、
  远程协助/设备列表/设置、橙色圆角选中态、底部链路状态），浅灰内容区两张等高白卡。
- 本机识别码卡：三位分组大黑字 + 复制；验证码/固定密码默认掩码 + 显示/刷新/修改。
- 远程协助卡：伙伴码输入（IDTextInputFormatter 自动分组、恢复上次 ID）、
  模式下拉（远程控制/文件传输/摄像头/终端/端口转发）+ 橙色连接；回车直连。
- 设备列表页 = 既有 ConnectionPage（分组侧栏/在线筛选/peer 卡）；平台图标改
  在线 coral / 离线灰；状态栏去重（仅 rail 底部一条）。
- 配色：MyTheme.accent 蓝 → coral #FF6A3D 族；peer 卡头图渐变同步 coral；
  浅/深主题均适配（主题默认跟随系统，设置可切）。
- 窗口：主窗口默认 980x640、最小 960x620；双卡并排断点 660，窄窗竖排。
- 美术自有：`flutter/assets/zc-logo-coral.svg` / `zc-logo-white.svg`
  （由 res/logo.svg 换色派生），**不含向日葵任何图标/素材/文案**。

## 2. 回归面

- 连接/输入/文件/摄像头/终端/端口转发全部走既有 `connect()` 与 Get 注册控制器；
  IndexedStack 保活 ConnectionPage（控制器注册时序：ConnectionPage 先建）。
- 删除的旧主页件：buildIDBoard/buildPasswordBoard(2)/buildTip/buildPopupMenu/
  左 pane 滚动容器；`custom_password` 导入保留（setPasswordDialog 仍用）。
- connection_page 底部 OnlineStatusWidget 移除（rail 提供），其余不动。
- 移动端/ Web 不受影响（改动仅 desktop 主页 + 共享配色/peer 卡色）。

## 3. 验收证据

- `flutter analyze`：新代码零 error（仅存量死文件 request_approval_menu 两条，
  无引用不参与编译，v2.2.1 起即存在）。
- 截图循环 6 轮（D:\cache\ui-2…ui-9）：主页对照参考图收敛；设备列表页配色/状态栏收敛。
- 实测交互：rail 切换远程协助↔设备列表；协助卡「连 接」→ 开出
  `253375647@g32 - Remote Desktop` 会话窗（连接主流程通）。
- `test/verify-windows.sh` 四条全 PASS（部署后复跑）。
- 已知坑：新 UI 包与已安装服务**不能并行**（ipc 单归属，第二实例每秒 reset 后退出）；
  截图验收须停服务跑用户态，或直接 MSI 升级。构建前必须先杀旧进程否则 LNK1104。
