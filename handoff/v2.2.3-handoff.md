## 1. 改了什么

- 用户反馈 v2.2.2 的 coral 橙"太橘太紧张"，要求与 logo 品牌配色相当。
  品牌标实为**蓝→青渐变环**（res/logo.svg / res/128x128.png / exe 图标：
  #0071FF→#00BFE1）。全量换色：
  - `MyTheme.accent/accent50/accent80/button` → #0071FF 族；`idColor` → #00A6E8
  - `grayBg` → 冷灰 #F3F6FA；主页卡片描边 #E3E8EF、输入填充 #F1F5F9（浅）/
    #161A20（深）；rail 描边同步
  - peer 卡在线头图渐变 → [#0071FF, #00BFE1]；离线 → 冷灰；平台图标离线色冷灰
  - 连接按钮/导航选中态/复制等图标色随 accent 自动归蓝
- **月亮/太阳切换钮**（rail 品牌行右）：`MyTheme.currentThemeMode()` 判态，
  点击 `changeDarkMode(light/dark)` 持久化到既有主题选项（设置页同步），
  图标 moon↔sun 互换；setState 刷新（非 Obx，避免无 Rx 报错）。
- 美术：删 `zc-logo-coral.svg`，增 `zc-logo-brand.svg`（蓝→青）；white 版保留。
